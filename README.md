## 질문
"스마트폰·미디어를 오래 쓰면 정말 공부 시간이 줄어드는가?"

## 왜 이 주제인가 (팀이 씁니다)

저희 세명 모두 미디어가 필수가 되어가면서 미디어 사용시간이 늘어나는 만큼 요즘 사람들에게 큰 영향을 미치는 지, 그것이 중요한 공부 시간에도 큰 영향 즉 문제를 일으키는지 궁금합니다.

- 20607 김연서: 미디어 사용이 학습에 미치는 영향을 알아보고 올바른 미디어 활용방법을 찾고싶어 선택했다
- 20805 김서현: 미디어 사용량이 정말 청소년 학습에 큰 영향을 미치는지 궁금해서 선택했다.
- 20806 김희승: 미디어 사용량과 공부 시간의 관계가 궁금해졌고, 실제 데이터를 통해 두 변수 사이의 관계를 분석하고자 선택했다

## 방법

**회귀:** 우리 팀은 스마트폰과 미디어 이용 시간이 증가할수록 공부시간이 감소하는지 알아보고자 한다. 공부시간을 숫자로 예측하고 스마트폰과 미디어 이용시간과의 관계를 분석하기 위해 회귀 분석을 선택했다.

**분석 과정(실제로 한 일, 단계마다 무엇을·어떻게·왜):**

1. **데이터 수집:** 2015년 성인,청소년 스마트폰 인식 조사 자료를 수집했다, 자료가 오래되었다는 한계와 너무 적다는 한계를 확인해서 2024~2026년의 최신 공공데이터를 추가로 찾는다.
2. **변수 선택:** 스마트폰,미디어 이용 시간을 입력 변수로, 공부시간을 목표 변수로 설정할 예정이다. 실제 데이터에 두 변수가 모두 있는지 학인한 뒤 최종 결정한다.
3. **전처리:** 결측치, 중복 자료, 자료형 오류와 비정상적인 값을 확인하고 처리한다. 실제 데이터의 특성을 확인한 뒤 삭제 또는 대체 여부를 결정한다.
4. **분할**

## 결과 해석 (팀이 씁니다)

### 사용한 지표와 수치

- MAE(평균 절대 오차): 159.95분
- RMSE(평균 제곱근 오차): 199.53분
- R²(결정계수): 0.121
- 교차검증 RMSE: 그래디언트 부스팅 198.28분으로 비교 모델 중 가장 낮음.

### 기준선(평균 모델 · 다수 범주 찍기 · 향상도 1 등)과 비교하면

우리 팀은 모든 학생의 공부 시간을 학습 데이터의 평균값으로 예측하는 평균 모델을 기준선으로 사용했다.

- 기준선의 교차검증 RMSE: 211.71분
- 그래디언트 부스팅의 교차검증 RMSE: 198.28분

그래디언트 부스팅은 기준선보다 RMSE가 약 13.43분 낮았으며, 약 6.34% 개선되었다. 따라서 스마트폰 사용 시간 등의 변수를 활용한 모델이 단순히 평균값만 예측하는 모델보다 나은 결과를 보였다.

### 이 결과가 뜻하는 것(우리 팀의 해석)

스마트폰 사용 시간과 학년, 성별, 경제적 수준 등의 정보를 활용하면 학생들의 공부 시간을 어느 정도 예측할 수 있었다. 하지만 R²가 0.121로 높지 않아 공부 시간에는 우리가 사용한 변수 외에도 다양한 요인이 영향을 미칠 수 있다고 해석했다.

### 우리 팀이 찾아낸 것(인사이트 3개: 헤드라인 → 근거 수치 → 뜻 → 상식과 다른 점)

**1. 복잡한 모델이 단순한 평균 예측보다 나은 결과를 보였다.**

- 근거 수치: 기준선 RMSE 211.71분, 그래디언트 부스팅 RMSE 198.28분
- 뜻: 여러 변수를 활용한 머신러닝 모델이 공부 시간을 더 잘 예측했다.
- 상식과 다른 점: 복잡한 모델이라고 무조건 좋은 것은 아니지만, 이번 분석에서는 그래디언트 부스팅이 가장 좋은 성능을 보였다.

**2. 모델의 공부 시간 예측에는 한계가 있었다.**

- 근거 수치: R² 0.121
- 뜻: 모델이 공부 시간의 차이를 설명하는 정도가 약 12.1%에 그쳤다.
- 상식과 다른 점: 스마트폰 사용 시간이 공부 시간과 관련이 있을 것이라고 예상했지만, 스마트폰 사용 시간 등의 변수만으로 공부 시간을 충분히 설명하기는 어려웠다.

**3. 예측값과 실제 공부 시간 사이에는 차이가 존재했다.**

- 근거 수치: MAE 159.95분, RMSE 199.53분
- 뜻: 모델의 예측값이 실제 공부 시간과 상당한 차이를 보일 수 있었다.
- 상식과 다른 점: 여러 변수를 함께 활용하고 모델을 최적화하더라도 개인별 공부 시간을 정확하게 예측할 수 있는 것은 아니었다.

## 한계

### 이 결과를 믿을 수 없는 이유(수치로)

- R²가 0.121로 낮아 공부 시간의 차이 중 약 12.1%만 모델이 설명했다.
- MAE가 159.95분으로, 실제 공부 시간과 예측값 사이에 평균적으로 약 160분의 차이가 있었다.
- 사용한 데이터와 변수만으로는 개인의 공부 습관이나 주변 환경 등 모든 요인을 반영하기 어렵다.
- 이번 분석은 변수 사이의 관계를 살펴본 것이므로 스마트폰 사용이 공부 시간을 감소시킨다는 인과관계를 증명하지 못한다.

### 이 결과를 잘못 쓰면 생길 수 있는 일

스마트폰을 오래 사용하는 학생은 공부를 적게 한다고 단정하거나, 스마트폰 사용 시간만으로 학생의 학습 태도와 성실성을 판단할 수 있다. 하지만 공부 시간은 개인의 생활 습관과 학습 환경 등 다양한 요인의 영향을 받으므로 이러한 판단은 적절하지 않다.
