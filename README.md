## 질문
"스마트폰·미디어를 오래 쓰면 정말 공부 시간이 줄어드는가?"

## 왜 이 주제인가 (팀이 씁니다)
저희 세명 모두 미디어가 필수가 되어가면서 미디어 사용시간이 늘어나는 만큼 요즘 사람들에게 큰 영향을 미치는 지, 그것이 중요한 공부 시간에도 큰 영향 즉 문제를 일으키는지 궁금합니다.
- 20607 김연서: 미디어 사용이 학습에 미치는 영향을 알아보고 올바른 미디어 활용방법을 찾고싶어 선택했다
- 20805 김서현: 미디어 사용량이 정말 청소년 학습에 큰 영향을 미치는지 궁금해서 선택했다.
- 20806 김희승: 미디어 사용량과 공부 시간의 관계가 궁금해졌고, 실제 데이터를 통해 두 변수 사이의 관계를 분석하고자 선택했다

## 방법
회귀 : 우리 팀은 스마트폰과 미디어 이용 시간이 증가할수록 공부시간이 감소하는지 알아보고자 한다. 공부시간을 숫자로 예측하고 스마트폰과 미디어 이용시간과의 관계를 분석하기 위해 회귀 분석을 선택했다.
분석 과정(실제로 한 일, 단계마다 무엇을·어떻게·왜): 
1. 데이터 수집 : 2015년 성인,청소년 스마트폰 인식 조사 자료를 수집했다, 자료가 오래되었다는 한계와 너무 적다는 한계를 확인해서 2024~2026년의 최신 공공데이터를 추가로 찾는다.
2. 변수 선택 : 스마트폰,미디어 이용 시간을 입력 변수로, 공부시간을 목표 변수로 설정할 예정이다. 실제 데이터에 두 변수가 모두 있는지 학인한 뒤 최종 결정한다.
3. 전처리 : 결측치, 중복 자료, 자료형 오류와 비정상적인 값을 확인하고 처리한다. 실제 데이터의 특성을 확인한 뒤 삭제 또는 대체 여부를 결정한다.
