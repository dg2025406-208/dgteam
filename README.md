## 왜 이 주제인가 (팀이 씁니다)
저희 세명 모두 미디어가 필수가 되어가면서 미디어 사용시간이 늘어나는 만큼 요즘 사람들에게 큰 영향을 미치는 지, 그것이 중요한 공부 시간에도 큰 영향 즉 문제를 일으키는지 궁금합니다.
- 20607 김연서: 미디어 사용이 학습에 미치는 영향을 알아보고 올바른 미디어 활용방법을 찾고싶어 선택했다
- 20805 김서현: 미디어 사용량이 정말 청소년 학습에 큰 영향을 미치는지 궁금해서 선택했다.
- 20806 김희승: 미디어 사용량과 공부 시간의 관계가 궁금해졌고, 실제 데이터를 통해 두 변수 사이의 관계를 분석하고자 선택했다
